- 7 PM metrics

- Sample artifacts

- Export skill quality report

- Upload artifact
- Choose metric
- View scorecard
- Export report

## v1.0: CI/CD quality gates

- GitHub Action
- PR comments
- Fail PR if launch criteria not met
